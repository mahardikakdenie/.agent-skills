# Admin Portal Lib

Shared non-component infrastructure and utilities live here.

- `api-client`: current service-layer HTTP infrastructure used by colocated services.
- `react-query`: TanStack Query client/provider setup.
- `http-client`: legacy HTTP client abstractions still used by older services.
- `formatter`, `utils`, `app-utils`, `toast`, `token-storage`, `password`, `email-template-html`: shared utilities.
