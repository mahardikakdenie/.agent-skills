## How to execute Batch 2

1. Run `pnpm prepare:batch2-sources` from `feat_ui` to refresh this map.
2. In your Batch 2 prompt session, read:
- All files in `packages/ui/docs/normalization/per-app/*_baseline-summary.md`.
- For each app in table above: its `02-design-system-foundation.md` and `06-component-standards.md`.
3. When the prompt references `<APP_PATH>`, use the `APP_PATH override` column from this table for that app.
4. Commit only on `feat/ui`.
